# Debugger #217 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the debugger requests of #217 (terminal-mode identity, breakpoint sync, skip counts, detach, settings,
listener check) as interfaces-adt 14.0.0 plus adt-clients 28.0.0, with unit tests, on-premise measurements and docs.

**Architecture:**
- **The contract first.** It changes in `@mcp-abap-adt/interfaces-adt`, in its own repository and PR, and the user publishes it.
- **Then the implementation.** adt-clients moves to the published contract and implements it in `src/runtime/debugger/abap.ts`
  (one function per request) and `AbapDebugger.ts` (one member per request, answered through a result strategy).
- **Every new wire behaviour gets a unit test** against a mocked connection, then an integration measurement on premise.

**Tech Stack:** TypeScript 6 (interfaces repo: 5.9), Jest (`npx jest --runInBand`), biome, fast-xml-parser.

**Spec:** `docs/superpowers/specs/2026-10-11-debugger-217-design.md` (this branch). Every task reads it. The spec decides
where the plan is silent.

```ts
/**
 * The parameters SAP keys a listener and its breakpoints on, by mode. `terminal` mode sends no `requestUser` — the
 * server reads none there — except on a breakpoint DELETE, which requires the parameter in every mode: left out it
 * answers 400 `ExceptionParameterNotFound`, empty it answers 200 (on premise, 2026-10-11).
 */
function identityQuery(identity: IDebuggerIdentity, purpose?: 'delete'): Record<string, string> {
  if (identity.debuggingMode === 'user') {
    return { debuggingMode: 'user', requestUser: identity.requestUser, terminalId: identity.terminalId, ideId: identity.ideId };
  }
  return {
    debuggingMode: 'terminal',
    ...(purpose === 'delete' ? { requestUser: '' } : {}),
    terminalId: identity.terminalId,
    ideId: identity.ideId,
  };
}

/** The identity's attributes on a breakpoints body, by mode. */
function identityAttributes(identity: IDebuggerIdentity): string {
  const user = identity.debuggingMode === 'user' ? ` requestUser="${escapeXml(identity.requestUser)}"` : '';
  return `debuggingMode="${identity.debuggingMode}" scope="external"${user} terminalId="${identity.terminalId}" ideId="${identity.ideId}"`;
}
```

```ts
export async function attach(
  connection: IAbapConnection,
  identity: IDebuggerIdentity,
  debuggeeId: string,
  dynproDebugging = true,
  server?: string,
): Promise<IAdtWireResponse> {
  // The server attaches by debuggeeId; it reads debuggingMode, and requestUser only in user mode (server source).
  const who = identity.debuggingMode === 'user'
    ? { debuggingMode: 'user', requestUser: identity.requestUser }
    : { debuggingMode: 'terminal' };
  return connection.makeAdtRequest({
    url: `${DEBUGGER}?${query({ method: 'attach', debuggeeId, ...who, dynproDebugging })}`,
    method: 'POST',
    timeout: getTimeout('default'),
    headers: { Accept: 'application/xml', ...(server ? { saplb: server } : {}) },
  });
}
```

```ts
function breakpointRow(bp: IDebuggerBreakpoint, only: string): string {
  const condition = (bp as { condition?: string }).condition;
  if (condition !== undefined && bp.kind !== 'line') {
    // The type forbids it; a cast can still get here. The server ignores a condition on other kinds, so sending it
    // would arm a breakpoint that stops unconditionally — refuse instead.
    throw new Error(`condition is accepted on a line breakpoint only, not on kind "${bp.kind}"`);
  }
  const cond = condition ? ` condition="${escapeXml(condition)}"` : '';
  const skip = bp.skipCount !== undefined ? ` skipCount="${bp.skipCount}"` : '';
  return `  <breakpoint kind="${bp.kind}" ${breakpointTarget(bp)}${cond}${skip}${only}/>`;
}

export function buildSyncBreakpointsXml(identity: IDebuggerIdentity, sync: IDebuggerBreakpointSync): string {
  const scope =
    sync.scope === 'full'
      ? '<syncScope mode="full"/>'
      : `<syncScope mode="partial">${sync.objects.map((uri) => `<adtcore:objectReference adtcore:uri="${escapeXml(uri)}"/>`).join('')}</syncScope>`;
  const rows = sync.breakpoints.map((bp) => breakpointRow(bp, '')).join('\n');
  return (
    '<?xml version="1.0" encoding="UTF-8"?>\n' +
    `<dbg:breakpoints ${ADT_NAMESPACES} ${identityAttributes(identity)}>\n  ${scope}\n${rows ? `${rows}\n` : ''}</dbg:breakpoints>`
  );
}
```

```ts
/** Ask whether a listener for the identity would conflict. Starts nothing: 200 with an empty body is "free"; a conflict is 409 `conflictDetected`; a missing authorization (`user` mode) is 403, checked first. */
export async function checkListener(connection: IAbapConnection, identity: IDebuggerIdentity): Promise<IAdtWireResponse> {
  return connection.makeAdtRequest({
    url: `${DEBUGGER}/listeners?${query({ ...identityQuery(identity), checkConflict: true })}`,
    method: 'GET',
    timeout: getTimeout('default'),
    headers: { Accept: 'application/xml' },
  });
}

const conflictParser = new XMLParser({ ignoreAttributes: false, attributeNamePrefix: '', parseTagValue: false, trimValues: true, removeNSPrefix: true });

/** Who holds the user's debugging, read from a 409 answer of a listener request; `undefined` for anything else. */
export function readListenerConflict(error: IAdtError): { conflictText: string; ideUser?: string } | undefined {
  const response = error.response;
  if (!response || response.status !== 409 || typeof response.data !== 'string' || !response.data) return undefined;
  let entries: unknown;
  try {
    entries = conflictParser.parse(response.data)?.exception?.properties?.entry;
  } catch {
    return undefined;
  }
  const list = (Array.isArray(entries) ? entries : entries ? [entries] : []) as Array<{ key?: string; '#text'?: string }>;
  const value = (key: string) => list.find((e) => e.key === key)?.['#text'];
  const conflictText = value('conflictText');
  if (!conflictText) return undefined;
  const ideUser = value('ideUser');
  return ideUser ? { conflictText, ideUser } : { conflictText };
}
```

  - **A malformed body.** If `fast-xml-parser` does not throw on it but returns partial nodes, the `conflictText` check
