# Plan: the verdict carries the connection's session code and sessionLost

Goal: `docs/superpowers/2026-11-12-verdict-session-goal.md`. Spec:
`docs/superpowers/2026-11-12-verdict-session-spec.md` (sections cited as "spec §n"). The
goal's invariants and the spec's decisions bind every step; a step that cannot be done as
written stops and goes back to the owner.

## Rules for every step

- **npm scripts only.** No `npx`, `npm exec`, `node_modules/.bin`, `ts-node`, `timeout`.
  Root scripts in each repository: `npm run build`, `npm run test:check`,
  `npm run lint:check`, `npm test` (adt-clients repository), `npm run check`.
- **Registry dependencies only.** Every dependency resolves from registry.npmjs.org. After
  any install, the lockfile is checked: `"link": true` only for the repository's own
  workspace siblings (in adt-clients: the three packages); nothing else linked, nothing
  resolved from a path. Lockfiles are regenerated by npm, never edited by hand.
- **Production code:** no cast, `any`, non-null `!`, `@ts-ignore`/`@ts-expect-error`, or
  regular expression; values from outside the type system (the thrown value) read as own
  data properties in plain code; no timeout, no retry, no resend.
- **Tests first.** Each code step writes its tests, runs them red against today's code,
  then changes the code until green. After green, each check named in the step is broken
  deliberately on its own, the tests go red, and the break is reverted.
- **Commits by path** (`git add <paths>`, never `-A`), each message ending with:

  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_013FwzVzuPQdYVh3bHZmipzj
  ```

  No `--no-verify`, no force-push.
- **CI after each push**: the PR's checks are watched to the end; a red check is fixed
  before the next step. Before a push, CI's own step list is run locally at the root:
  `npm ci --ignore-scripts`, `npm audit --audit-level=moderate`, `npm run build`,
  `npm run test:check`, `npm run lint:check`, `MCP_ENV_PATH=/tmp/nonexistent-env npm test`,
  `npm run check:packed`, `npm run check:publish`, `npm run check:publish:root`
  (`.github/workflows/ci.yml`).
- **Main checkouts are not switched.** Work happens in worktrees under `.worktrees/`.
- **No live SAP run** in this task (spec §7: unit-only; the server's live run proves it).
- **Working documents leave before the release.** Goal, spec and plan are deleted in the
  last commit before tagging; what they still owe (the server follow-up, unit-only
  evidence) goes into the PR description first.
