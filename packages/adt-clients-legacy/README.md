# @mcp-abap-adt/adt-clients-legacy

Clients for legacy SAP ABAP systems (7.40), built on
[`@mcp-abap-adt/adt-clients`](../adt-clients). The consumer declares the system
type by constructing a legacy class; nothing here detects it.

Work in progress: the package is a skeleton and exports nothing yet.
